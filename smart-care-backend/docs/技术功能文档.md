# 智慧养老系统技术功能文档

## 1. 项目概述

本项目基于若依开源框架进行二次开发，建设一套面向居家养老场景的智慧养老综合服务平台。系统围绕“设备接入、数据采集、异常预警、工单处置、健康评估、家属协同、社区监管”展开，支持管理端、社区端、家属端三类使用角色，实现老人健康状态实时感知、风险事件自动发现、处置流程闭环管理及服务过程留痕。

系统通过模拟或接入各类居家传感器设备，包括智能床垫、门磁、药盒、红外/雷达、烟雾/燃气环境传感器等，采集老人活动和健康数据；通过规则判断和业务分析，自动生成预警记录、处置工单和健康报告，满足社区监管与家属照护双重需求。

## 2. 建设目标

1. 建立老人、家属、设备、预警、工单、随访、健康报告等业务信息一体化管理平台。
2. 实现设备数据采集、异常识别、预警分级、消息通知、工单派发和处置回写的闭环。
3. 为社区提供辖区老人一张图监控、重点老人专项管理和服务记录管理能力。
4. 为家属提供实时状态查看、分级预警、日报周报、紧急联系人、SOS 一键求助等能力。
5. 支持 AI 大模型健康评估与饮食建议生成，提升智慧照护辅助决策能力。

## 3. 角色与权限设计

系统当前按三类角色进行权限控制：

### 3.1 家属角色

家属仅可查看本人已关联老人的数据，主要访问：

1. 家属门户
2. 与本人关联老人的预警记录
3. 与本人关联老人的健康报告
4. 与本人关联老人的服药执行情况
5. 与本人关联老人的随访记录
6. 紧急联系人维护与 SOS 求助

### 3.2 社区角色

社区用户主要访问：

1. 社区总览
2. 社区大屏
3. 老人档案
4. 家属关联
5. 预警记录
6. 处置工单
7. 健康报告
8. 巡访/随访记录
9. 重点老人管理
10. 服药计划与执行
11. 消息中心

### 3.3 管理员角色

管理员具备智慧养老全量业务访问权限，同时可访问：

1. 设备台账
2. 传感器流水
3. 预警规则配置
4. AI 健康评估
5. 系统日志
6. 权限与菜单配置

## 4. 系统架构

### 4.1 技术架构

1. 前端：Vue 3 + Element Plus + ECharts
2. 后端：Spring Boot + Spring Security + MyBatis
3. 数据库：MySQL
4. 权限体系：若依角色、菜单、权限标识
5. 消息方式：站内消息中心
6. AI 能力：通义千问 / 文心一言接口接入

### 4.2 总体业务链路

1. 设备台账建立与老人绑定
2. 传感器数据上报写入流水
3. 分析服务识别异常并生成预警
4. 预警自动派发工单
5. 工单处置状态回写预警状态
6. 预警、工单、健康报告、消息通知联动展示

## 5. 核心功能模块

## 5.1 基础档案管理

### 5.1.1 老人档案管理

支持老人基础信息维护，包括：

1. 姓名、年龄、性别、联系电话、住址
2. 健康状态、纳管状态、责任人
3. 下次随访时间、干预措施
4. 跟进结果、最近处置人
5. 纳管开始时间、解除原因

页面可直接联动查看该老人的：

1. 设备数量
2. 预警数量
3. 未结工单数

### 5.1.2 家属关联管理

支持老人和家属账号建立绑定关系，主要功能包括：

1. 选择老人
2. 选择家属账号
3. 自动带出家属姓名与电话
4. 设置亲属关系
5. 标记紧急联系人

系统已支持“按当前登录家属账号只查看自己关联老人的数据”。

## 5.2 设备管理与数据采集

### 5.2.1 设备台账

支持设备全生命周期管理，包括：

1. 设备编号
2. 设备名称
3. 设备类型
4. 绑定老人
5. 设备状态
6. 安装时间
7. 备注信息

当前已统一设备类型、设备状态字典展示。

### 5.2.2 传感器流水

支持传感器实时数据管理与模拟上报，包括：

1. 心率
2. 呼吸率
3. 离床状态
4. 烟雾值
5. 门磁状态
6. 药盒状态

支持单条模拟上报和批量模拟上报，便于系统联调与演示。

## 5.3 预警规则与异常预警

### 5.3.1 预警规则配置

支持按设备类型、指标类型、阈值和持续时间配置预警规则，支持：

1. 设备类型选择
2. 指标类型选择
3. 比较条件设置
4. 阈值设置
5. 持续时间设置
6. 预警等级设置
7. 启停控制

### 5.3.2 异常预警记录

系统支持根据传感器流水和规则分析自动生成预警记录，主要包含：

1. 预警等级
2. 预警类型
3. 预警描述
4. 处理状态
5. 关联工单

当前已实现：

1. 预警记录与工单双向跳转
2. 工单状态回写预警处理状态
3. 药盒漏服自动生成预警

### 5.3.3 预警等级划分

系统按三级预警进行管理：

1. 一级：关注
2. 二级：警示
3. 三级：紧急

典型场景包括：

1. 作息异常
2. 长时间未活动
3. 夜间起夜增多
4. 漏服药
5. 门未关
6. SOS 求助
7. 烟雾异常
8. 跌倒/无应答类事件

## 5.4 工单处置闭环

### 5.4.1 自动派单

系统在预警记录生成后，可自动创建处置工单，避免人工漏派。

### 5.4.2 工单管理

支持工单全过程管理，包括：

1. 待接单
2. 处理中
3. 已结办

### 5.4.3 闭环联动

已实现：

1. 预警生成自动派单
2. 工单处理状态回写预警状态
3. 工单与预警双向追踪

## 5.5 社区端功能

### 5.5.1 社区总览

已建设“辖区老人一张图监控”页面，展示：

1. 在管老人总数
2. 在线设备总数
3. 今日预警数量
4. 紧急预警数量
5. 待办工单数量
6. 近 7 天随访数量

### 5.5.2 社区大屏

1. 24 小时活动热力图
2. 心率/呼吸曲线
3. 预警趋势图
4. 高风险老人排行
5. 设备类型分布
6. 最新预警和待办工单看板

### 5.5.3 重点老人管理

已单独建设重点老人管理页面，支持查看：

1. 重点纳管老人
2. 高风险人群
3. 工单积压老人
4. 长期未巡访老人

并已支持维护：

1. 纳管状态
2. 责任人
3. 下次随访时间
4. 干预措施
5. 跟进结果
6. 最近处置人

8. 解除原因

### 5.5.4 巡访/随访管理

系统已建设日常随访记录与健康报告模块，支持：

1. 例行巡访
2. 健康随访
3. 送药记录
4. 服务内容留痕

## 5.6 家属端功能

### 5.6.1 家属门户

已建设家属门户页面，支持围绕已关联老人进行照护查看，主要包括：

1. 老人实时状态查看
2. 心率/呼吸趋势图
3. 分级预警查看
4. 日报周报查看
5. 今日服药计划与执行摘要
6. 紧急联系人
7. SOS 一键求助
8. 一键呼叫

### 5.6.2 实时状态查看

当前支持展示：

1. 在床
2. 活动
3. 外出
4. 离线
5. 门磁状态
6. 今日服药情况
7. 健康评分

### 5.6.3 紧急联动

家属端支持：

1. 维护紧急联系人
2. 一键拨打家属、社区热线、120、110
3. 发起 SOS 求助

SOS 已接入：

1. 预警记录
2. 工单自动派发
3. 消息通知

## 5.7 健康评估与日报周报

### 5.7.1 健康评估报告

系统支持按日报/周报记录老人健康状况，内容包括：

1. 睡眠评分
2. 活力评分
3. AI 评估结论
4. 风险判断

### 5.7.2 家属与社区查看

家属可查看已关联老人的健康报告；社区可查看辖区老人报告，便于：

1. 异常趋势追踪
2. 健康变化掌握
3. 服务安排参考

## 5.8 服药计划与执行

### 5.8.1 服药计划

已建设服药计划模块，支持：

1. 药品名称
2. 单次剂量
3. 用药方式
4. 早/中/晚服药时段
5. 计划时间
6. 起止日期
7. 启停控制

### 5.8.2 服药执行

已建设服药执行记录模块，支持展示：

1. 计划时间
2. 实际执行时间
3. 执行状态
4. 数据来源

执行状态包括：

1. 待服药
2. 已服药
3. 漏服

### 5.8.3 药盒联动

智能药盒上报 `taken / waiting / missed` 后，系统可自动：

1. 同步服药执行记录
2. 在家属门户中展示今日服药摘要
3. 对漏服事件生成预警
4. 进入消息中心
5. 进入工单派发链路

## 5.9 消息通知中心

已建设站内消息中心，不依赖 App 或小程序即可完成系统内消息触达。

当前支持：

1. 预警创建消息
2. 工单创建消息
3. 工单状态变更消息
4. 家属查看本人消息
5. 社区和管理员查看本角色消息
6. 已读/未读管理
7. 从消息跳转到预警或工单页面

## 5.10 AI 大模型辅助评估

已建设 AI 健康评估独立页面，支持调用：

1. 通义千问
2. 文心一言

支持输出：

1. 老人健康评估
2. 饮食建议
3. 随访与干预建议

## 8. 已实现的关键闭环

### 8.1 预警闭环

传感器上报 -> 异常识别 -> 预警生成 -> 消息通知 -> 自动派单 -> 工单处置 -> 预警状态回写

### 8.2 SOS 闭环

家属门户发起 SOS -> 系统生成紧急预警 -> 自动生成工单 -> 社区处置 -> 状态回写

### 8.3 服药闭环

服药计划配置 -> 药盒状态上报 -> 服药执行记录生成 -> 漏服预警 -> 消息通知 -> 工单跟进

当前系统已完成智慧养老平台的核心主干建设，能够支撑演示、汇报及阶段性交付，主要表现为：

1. 基础档案、设备、传感器、预警、工单、健康报告、随访、消息、AI、服药模块已形成业务体系。
2. 社区端、家属端、管理端均已有可用页面与菜单入口。
3. 关键业务闭环已打通，具备实时感知、异常发现、自动派单、结果回写能力。
4. 已补充多名老人、家属、设备、随访、工单、健康报告等演示数据，适合现场演示和汇报。

## 10. 后续可继续优化方向

系统已具备核心功能，后续如需进一步深化，可从以下方向继续优化：

1. 社区辖区/网格维度数据范围隔离

6. 统计分析中心，如闭环率、误报率、响应时效、设备在线率

本系统已完成智慧养老平台的基础框架搭建与核心业务功能实现，能够面向“社区监管 + 家属照护”双场景开展应用，具备较强的扩展性和演示交付能力。系统已初步形成“设备感知、数据采集、异常预警、工单闭环、服务留痕、AI 辅助”的智慧养老业务体系，可作为后续深化建设和正式推广部署的基础平台。
