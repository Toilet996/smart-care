# 智慧养老系统项目汇报 PPT 提纲

## 1. 封面页

建议内容：

1. 项目名称：智慧养老综合管理系统
2. 汇报主题：项目建设情况汇报
3. 汇报单位
4. 汇报人
5. 汇报日期

建议展示风格：

1. 简洁正式
2. 可配社区养老、智慧医疗、老人关怀相关背景图

## 2. 项目建设背景

建议讲述内容：

1. 人口老龄化趋势加快，社区居家养老服务需求持续增长
2. 传统养老服务存在人工巡查成本高、异常发现滞后、家属协同不足等问题
3. 需要建设一套集设备感知、风险预警、工单处置、服务记录、家属协同于一体的智慧养老平台

可提炼的关键词：

1. 居家养老
2. 风险预警
3. 社区监管
4. 家属协同

## 3. 项目建设目标

建议内容：

1. 建立老人、家属、设备、预警、工单、服务记录一体化管理平台
2. 实现老人状态实时感知和异常自动预警
3. 实现社区工单自动派发与处置闭环
4. 实现家属实时查看、预警接收、SOS 求助
5. 引入 AI 辅助生成健康评估和饮食建议

## 4. 系统总体架构

建议用一页图示表达：

1. 感知层：智能床垫、门磁、药盒、烟感、雷达等设备
2. 数据层：传感器流水、业务数据库
3. 分析层：规则引擎、AI 分析
4. 业务层：预警、工单、巡访、报告、服药、消息
5. 应用层：管理端、社区端、家属端

建议配图说明：

设备接入 -> 数据采集 -> 预警分析 -> 工单派发 -> 社区处置 -> 家属查看

## 5. 技术架构

建议内容：

1. 前端：Vue 3 + Element Plus + ECharts
2. 后端：Spring Boot + Spring Security + MyBatis
3. 数据库：MySQL
4. 基础框架：若依
5. AI 模型：通义千问 / 文心一言

建议突出：

1. 架构成熟
2. 扩展性强
3. 便于后续部署和维护

## 6. 系统角色设计

建议内容：

### 管理端

1. 负责基础配置、设备管理、预警规则、系统监管

### 社区端

1. 负责辖区老人监控、预警处置、巡访随访、重点人群管理

### 家属端

1. 负责实时查看、预警接收、日报周报、紧急联系和 SOS 求助

## 7. 管理端建设内容

建议列出：

1. 老人档案管理
2. 家属关联管理
3. 设备台账管理
4. 传感器流水管理
5. 预警规则配置
6. 异常预警记录
7. 处置工单管理
8. 健康评估报告
9. 服药计划与执行
10. 消息中心
11. AI 健康评估

## 8. 社区端建设内容

建议列出：

1. 辖区老人一张图监控
2. 社区总览与社区大屏
3. 预警工单自动派发
4. 工单处置闭环
5. 日常巡访与健康随访
6. 重点老人/高风险人群专项管理

## 9. 家属端建设内容

建议列出：

1. 家属门户
2. 老人实时状态查看
3. 分级预警推送
4. 历史日报周报
5. 今日服药计划与执行摘要
6. 紧急联系人设置
7. SOS 一键求助
8. 一键呼叫

## 10. 核心业务闭环

建议用流程图讲解：

### 预警闭环

1. 设备上报数据
2. 系统分析异常
3. 自动生成预警
4. 自动派发工单
5. 社区处置反馈
6. 状态回写闭环

### SOS 闭环

1. 家属发起 SOS
2. 系统生成紧急预警
3. 自动创建工单
4. 社区处理
5. 家属查看状态

### 服药闭环

1. 配置服药计划
2. 药盒状态上报
3. 生成服药执行记录
4. 漏服触发预警
5. 消息通知和工单联动

建议总结：

1. 基于若依框架快速搭建，扩展性强

3. 多角色菜单与数据隔离
4. 预警、工单、消息自动联动
5. 家属端、社区端、管理端统一数据底座
6. 集成 ECharts 可视化和 AI 能力
