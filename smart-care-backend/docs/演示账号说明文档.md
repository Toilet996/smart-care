# 智慧养老系统演示账号说明

## 1. 文档说明

本文档用于智慧养老系统演示、汇报和验收场景，说明系统当前可用的测试账号、账号角色、可查看数据范围及推荐演示入口。

## 2. 角色说明

系统当前主要包含三类演示角色：

1. 管理员
2. 社区端用户
3. 家属端用户

## 3.3 社区端演示账号

当前系统已完成社区角色、菜单和数据展示能力，但默认脚本中未单独固定创建一套“社区专用用户名”。

建议使用以下方式演示社区端：

### 方式一：使用现有账号分配社区角色

可将现有账号分配 `smartcare_community` 角色后进行演示，例如：

1. `ry`
2. 其他测试账号
3. 甲方指定的临时演示账号

### 方式二：使用管理员账号演示社区模块

若现场无需单独验证角色隔离，可直接使用 `admin` 账号进入以下页面进行演示：

1. 社区总览
2. 社区大屏
3. 重点老人管理
4. 老人档案
5. 预警记录
6. 处置工单
7. 随访记录
8. 消息中心

## 7. 注意事项

1. 家属账号已按“仅可查看本人关联老人数据”进行数据隔离。
2. 如需演示社区账号权限隔离，需先在系统中给指定账号分配 `smartcare_community` 角色。
3. 若现场菜单未立即刷新，建议重新登录后再演示。
4. 若密码已在本地环境中被修改，请以当前数据库实际密码为准。
